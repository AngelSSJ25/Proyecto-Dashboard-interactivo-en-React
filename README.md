## Descripción

Dashboard táctico para explorar la composición histórica del catálogo de Netflix por país, año de estreno, género, director y formato. La Fase 1 documenta la audiencia, los indicadores y el preprocesamiento del CSV. El diseño contempla React, PostgreSQL y una API de lectura.
